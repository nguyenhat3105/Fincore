# Architecture Decision Records

Architecture Decision Records capture decisions that materially affect FINCORE's design. Accepted records are immutable; a later decision supersedes an earlier record instead of rewriting its history.

| [0003](0003-use-transactional-outbox.md) | Publish integration events through a transactional outbox | Accepted |
| [0004](0004-store-money-in-minor-units.md) | Store money in ISO 4217 minor units | Accepted |
